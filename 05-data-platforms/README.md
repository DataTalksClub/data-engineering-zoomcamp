# Data Platforms

## Units

1. [Introduction to Bruin](01-introduction.md) - Introduce Bruin as an end-to-end data platform that combines ingestion, transformations, orchestration, and quality checks.
2. [Getting Started with Bruin](02-getting-started.md) - Install the Bruin CLI and VS Code extension, then initialize a project with pipeline and connection config files.
3. [Building an End-to-End Pipeline with NYC Taxi Data](03-nyc-taxi-pipeline.md) - Build a three-layer NYC taxi pipeline in Bruin with ingestion, staging, and reports assets, a seed, and quality checks.
4. [Using Bruin MCP with AI Agents](04-bruin-mcp.md) - Use the Bruin MCP server with AI agents in Cursor, VS Code, or Claude Code to build and query pipelines.
5. [Deploying to Bruin Cloud](05-bruin-cloud.md) - Deploy a Bruin pipeline to Bruin Cloud by connecting a GitHub repository, setting connections, and enabling schedules.
6. [Core Concepts: Projects](06-core-concepts-projects.md) - Configure Bruin projects with .bruin.yml environments and connections, and validate them with bruin validate.
7. [Core Concepts: Pipelines](07-core-concepts-pipelines.md) - Define Bruin pipelines with one schedule, default connections, and a folder of assets for each pipeline.
8. [Core Concepts: Assets](08-core-concepts-assets.md) - Explain Bruin asset types, naming conventions, materialization strategies, and dependencies that drive lineage.
9. [Core Concepts: Variables](09-core-concepts-variables.md) - Use Bruin variables for run dates and custom parameters in SQL Jinja templates and Python environment variables.
10. [Core Concepts: Commands](10-core-concepts-commands.md) - Run Bruin CLI commands to run pipelines or assets, validate definitions, view lineage, and query data.
